M5Stack DJ Smart Hub

Independent project · Active development

The problem

Bring audio-reactive lighting and immediate operator controls into a compact system for live-event use. The project connects my interest in electronics with the practical demands of operating sound and lighting.

How the system is organized

Two M5Stack CoreS3 devices have separate responsibilities. The Brain handles line-in audio and control; the Controller handles its microphone input and physical DMX lighting output. ESP-NOW carries commands and status between them.

  • Audio and lighting: Spectrum analysis, tempo tracking, scene controls, and fixture profiles.
  • Operator interface: LVGL touch controls, device status, and a browser-based Field Router interface.
  • Testing: A behavior simulator exercises interface and control scenarios before separate hardware checks.

Project status

The repository contains firmware, interface code, simulator tests, and technical documentation. Development is ongoing. The screenshot demonstrates the browser interface; it does not establish radio performance or physical lighting-output performance.

Project technologies: M5Stack CoreS3, ESP32-S3, C++, PlatformIO, LVGL, ESP-NOW, DMX512, TypeScript.
