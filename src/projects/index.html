M5Stack DJ Smart Hub

Active development

Problem

Create a compact, responsive control system that turns live audio analysis into dependable lighting control while keeping performance controls immediate.

Approach

A two-device architecture separates line-in audio analysis, BPM and scene logic from physical DMX output. Low-latency wireless transport keeps both control surfaces synchronized.

Tools: M5Stack CoreS3, ESP32-S3, ESP-NOW, FFT analysis, LVGL, DMX512

ESP32 Smart-Light Retrofit

Active development

Problem

Extend the control and serviceability of rechargeable RGB uplights without discarding working power and LED hardware.

Approach

An ESP32-S3 retrofit adds internal DMX injection, an external wired fallback, ESP-NOW control, fixture profiles, and distinct normal and emergency blackout states.

Tools: ESP32-S3, ESP-NOW, DMX512, RS-485, embedded firmware, fixture profiles
