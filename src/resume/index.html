Smarter Software for 3D Printing

Grand Master Slice | In development

Developing Grand Master Slice, software that turns a digital 3D design into instructions a printer can follow. The project builds on existing open-source software, with Windows build tools, printer-setting checks, and automated tests in place. The goal is to adapt printing to each part’s shape and purpose for better quality and fewer failed prints. Planned features include varying printing speed, heat, and the amount of plastic inside a part, cleaner print starts, and easier color or spool changes during printing.
