# phelixestinvil.com

Source for Phelix Estinvil's professional résumé and technical portfolio.

## Current foundation

- One-page professional overview
- Experience and core-capabilities sections
- Selected-project index with expandable case-study structure
- Web résumé page with a reserved PDF-download state
- Responsive navigation and accessible focus states
- Dependency-free static build
- Non-deploying GitHub Actions verification

The repository intentionally excludes unverified employment dates, private working materials, and unsupported performance claims. The downloadable PDF résumé will be added after the remaining dates and contact details are confirmed.

## Local commands

```bash
npm ci
npm run check
npm run build
```

The production-ready static output is written to `dist/`.

## Publication status

The source repository is initialized, but hosting, GitHub Pages, DNS, analytics, and contact-form processing are not enabled yet.
